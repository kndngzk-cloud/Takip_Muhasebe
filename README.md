# Sipariş • Stok • Cari

Sipariş, stok ve cari hesap takibi için web uygulaması (iPhone / iPad / Mac'te ana ekrana eklenebilir).

- Ekranlar: `index.html`, `styles.css`, `app.js` (dış kütüphane yok)
- Veri tabanı: Supabase (PostgreSQL) — bağlantı bilgisi `config.js`
- Yayın: Netlify, bu depodaki her değişiklikte otomatik
